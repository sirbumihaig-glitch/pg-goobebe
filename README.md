# GOO BEBE × P&G — GitHub Pages

Site static: încărcați `index.html`, `style.css` și directorul `assets` în rădăcina repository-ului. În Settings → Pages, alegeți „Deploy from a branch”, ramura `main` și directorul `/ (root)`.

Domeniul solicitat `p&g.goobebe.ro` nu poate fi folosit ca domeniu web: caracterul `&` nu este permis în etichetele DNS. O alternativă este `pg.goobebe.ro`, dar trebuie aleasă de proprietar. După alegerea domeniului, introduceți-l în GitHub Pages la Custom domain și creați în DNS o înregistrare CNAME de la subdomeniul ales către `<utilizator-sau-organizație>.github.io`. Apoi activați HTTPS după ce GitHub validează domeniul. Niciun domeniu nu este configurat automat în această arhivă.

Imaginile Pampers și Femibion din secțiunile de produs sunt încărcate de pe site-uri externe și necesită conexiune la internet. Verificați drepturile pentru fotografii, logo-uri și mărci înainte de publicarea destinată publicului.
